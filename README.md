# English Coach

AI-агент для вивчення англійської для програмістів: уроки з власних матеріалів,
словник із картками, інтервальне повторення, тести й розмовна практика.

## Запуск (Windows, термінал PhpStorm)

Перший раз:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Вставте свій ключ у `.env`. Далі щоразу:

```
.venv\Scripts\activate
python web.py     # адмінка в браузері: http://127.0.0.1:8000
python main.py    # лише розмова, у консолі
```

## Доступ із телефона й ноутбука (Tailscale)

Застосунок лишається на цьому комп'ютері, Tailscale лише з'єднує ваші пристрої
в приватну мережу. У відкритий інтернет нічого не потрапляє.

1. Поставте Tailscale на комп'ютер і на телефон, в обох увійдіть одним акаунтом:
   https://tailscale.com/download
2. У `.env` розкоментуйте рядок `COACH_HOST=0.0.0.0`.
3. Запустіть `python web.py` — у терміналі з'явиться адреса для інших пристроїв.
4. Відкрийте її на телефоні. Tailscale на телефоні має бути увімкнений.

Щоб працював мікрофон у розмові з коучем, потрібен HTTPS. Його дає Tailscale:

```
tailscale serve --bg 8000
```

Команда видасть адресу виду `https://desktop-xxxx.tailXXXX.ts.net` — з нею
мікрофон працюватиме. Якщо Tailscale запитає дозвіл увімкнути HTTPS-сертифікати
для вашої мережі, погодьтеся: це безкоштовно. З `tailscale serve` рядок
`COACH_HOST` можна лишити закоментованим.

Умова одна: комп'ютер має бути увімкнений.

## Який ключ потрібен

За замовчуванням застосунок працює на безкоштовному Gemini. Ключ береться
на https://aistudio.google.com/apikey, картка не потрібна.

| Провайдер | Рядки в `.env` |
|---|---|
| Gemini (безкоштовно) | `COACH_PROVIDER=gemini`, `GEMINI_API_KEY=AIza...`, `COACH_MODEL=gemini-2.5-flash` |
| Anthropic (платно) | `COACH_PROVIDER=anthropic`, `ANTHROPIC_API_KEY=sk-ant-...`, `COACH_MODEL=claude-haiku-5-5` |

Список доступних для вашого ключа моделей: `python models.py`.
На безкоштовному рівні Gemini діють обмеження запитів за хвилину й за добу;
якщо ліміт вичерпано, застосунок про це повідомить.

## Розділи адмінки

| Розділ | Що робить |
|---|---|
| Матеріали | текст, фото, PDF або текстовий файл → урок зі словами й прикладами |
| Словник | картки слів і фраз, фільтри за категорією та рівнем |
| Повторення | інтервальне повторення карток (спрощений SM-2) |
| Тести | вибір перекладу та пропуск у реченні, без запитів до моделі |
| Розмова з коучем | діалог англійською з виправленням помилок |

## Структура

| Файл | Призначення |
|---|---|
| `web.py` | локальний сервер і API адмінки |
| `web/index.html` | інтерфейс адмінки |
| `coach/llm.py` | єдиний інтерфейс до моделі: Gemini або Anthropic |
| `coach/agent.py` | розмовний коуч: історія розмови |
| `models.py` | показує моделі, доступні для вашого ключа |
| `coach/prompts.py` | системний промпт коуча |
| `coach/tutor.py` | перетворення матеріалу на урок із картками |
| `coach/db.py` | база SQLite: матеріали, словник, повторення |
| `coach/quiz.py` | генерація тестів зі словника |
| `data/` | база `coach.db` і завантажені файли (створюється автоматично) |
| `main.py` | консольна версія розмови |
